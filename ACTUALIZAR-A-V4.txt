ACTUALIZAR A JADRIXSERVS BOT V4

1. Extrae este ZIP.
2. Copia todo dentro de tu carpeta actual del repositorio.
3. Acepta reemplazar archivos.
4. NO borres la carpeta oculta .git.
5. Abre PowerShell en la carpeta y ejecuta:

   git add .
   git commit -m "Actualizar JadrixServs Bot a version 4"
   git push

6. Render desplegará automáticamente.
7. En Render > Environment confirma:
   ADMIN_KEY = tu contraseña
   OPENAI_API_KEY = tu clave de API (opcional para IA)
   OPENAI_MODEL = gpt-5-mini
   SESSION_PATH = /data/baileys_auth
   DATA_DIR = /data/bot-control
8. Abre tu misma URL de Render.
9. Entra con ADMIN_KEY.
10. Escanea QR si lo solicita.

IMPORTANTE:
- La automatización de cobros está DESACTIVADA de forma inicial. Actívala manualmente en Clientes y cobros.
- Render gratis puede perder sesión, audios, clientes y configuración al reiniciarse. Para producción usa un plan con disco persistente.
- Haz respaldo JSON desde el panel.
