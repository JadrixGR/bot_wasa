JADRIXSERVS BOT V4.3 - ACTUALIZACIÓN LIMPIA

1. Descomprime JadrixServs-Bot-V4.zip.

2. Copia el CONTENIDO de la carpeta jadrixservs-bot-v4 dentro de la carpeta
   de tu repositorio. Acepta reemplazar los archivos.

3. No borres la carpeta .git.

4. IMPORTANTE: si tus respuestas antiguas estaban dentro de server.js o
   seed-data.js, guarda primero una copia de esos dos archivos fuera del
   repositorio. Para recuperar ese texto exacto hay que importarlo.

5. Elimina estos archivos viejos si todavía aparecen:
   server.js
   seed-data.js
   ACTUALIZAR-A-V3.txt
   ACTUALIZAR-A-V4.txt
   INSTRUCCIONES-ACTUALIZACION.txt
   INSTRUCCIONES-RAPIDAS.txt

6. Abre CMD dentro de la carpeta y ejecuta, una línea por vez:

   git rm --ignore-unmatch server.js seed-data.js ACTUALIZAR-A-V3.txt ACTUALIZAR-A-V4.txt INSTRUCCIONES-ACTUALIZACION.txt INSTRUCCIONES-RAPIDAS.txt
   git add -A
   git commit -m "Actualizar JadrixServs a V4.3"
   git push

7. En Render > Environment revisa:
   DATA_DIR=/data
   MEDIA_DIR=/data/media
   OPENAI_MODEL=gpt-5.6-luna
   OPENAI_API_KEY=tu clave de la plataforma de OpenAI

   Si la prueba muestra error 429, la clave ya está configurada pero la API
   no tiene saldo o alcanzó su límite. Agrega créditos en:
   https://platform.openai.com/settings/organization/billing/overview

8. Espera que el nuevo despliegue de Render finalice.

9. En WhatsApp del celular:
   Configuración > Dispositivos vinculados
   Elimina la sesión anterior del bot.

10. En el panel JadrixServs:
   WhatsApp > Cerrar sesión
   Espera el QR nuevo y escanéalo.

11. No pulses Reiniciar mientras diga "Autenticando".
   Debe cambiar automáticamente a "Conectado".

12. Si no conecta después de 45 segundos, pulsa "Forzar conexión" una vez
    y vuelve a esperar.

13. Prueba desde otro número esta frase exacta:
    ¿Cuál es el precio del Super Combo IA 2026?

    Debe recibir 3 mensajes separados, con "escribiendo..." antes de cada uno.

14. Abre Mensajes y archivos > Entrenamiento local.
    Allí puedes editar, activar y agregar respuestas sin depender de OpenAI.

IMPORTANTE:
- Render debe tener un disco persistente montado en /data.
- OPENAI_API_KEY se configura en Environment de Render, nunca en GitHub.
- ChatGPT Plus no incluye saldo de API; son facturaciones separadas.
- El archivo que inicia el bot es src/server.js.
