JADRIXSERVS BOT V4.8.3 - PROTOCOLO ACTUAL Y QR
================================================

QUÉ CORRIGE
- Corrige el estado CONNECTING que aparecía después de cerrar la sesión pero
  nunca entregaba el QR.
- Consulta automáticamente la revisión vigente de WhatsApp Web.
- Evita usar como primera opción la revisión antigua incluida en Baileys.
- Si aparece 405, cambia de versión y de perfil sin borrar clientes.
- Si pasan 20 segundos sin QR, cambia automáticamente de candidato.
- Conserva el cierre real de V4.8.2 y elimina solo /data/whatsapp-session.
- Conserva el logo Jadrix Serv Digital Solutions.
- Conserva todas las funciones y el diseño profesional.
- No cambia el esquema de datos, los clientes ni los mensajes configurados.

ANTES DE ACTUALIZAR
1. En el panel actual abre Clientes y cobros.
2. Pulsa "Descargar respaldo JSON" y guarda el archivo en tu computadora.
3. En Render abre tu MISMO servicio y entra a Disks.
4. Confirma:
   - Disk: jadrixservs-data
   - Mount Path: /data
   - DATA_DIR=/data
   - MEDIA_DIR=/data/media
5. No elimines, reemplaces ni desconectes el disco.
6. No crees otro servicio de Render para esta actualización.

ARCHIVOS QUE SE CONSERVAN EN RENDER
- /data/jadrixservs-v4.json             Base principal
- /data/jadrixservs-v4.backup.json      Copia automática
- /data/jadrixservs-v4.pre-v4.7.2.json  Copia fija existente
- /data/whatsapp-session                Sesión de WhatsApp
- /data/media                           Archivos multimedia

SUBIR A GITHUB
1. Descomprime JadrixServs-Bot-V4.8.3-QR-Protocolo-Actualizado.zip.
2. Copia el contenido de jadrixservs-bot-v4 sobre tu repositorio actual.
3. Acepta reemplazar los archivos, pero NO borres la carpeta .git.
4. Desde PowerShell ejecuta:

   git rm --ignore-unmatch PASOS-ACTUALIZAR-V4.8.txt PASOS-ACTUALIZAR-V4.8.1.txt PASOS-ACTUALIZAR-V4.8.2.txt
   git add -A
   git commit -m "Actualizar protocolo WhatsApp y QR en V4.8.3"
   git push

5. Render desplegará el cambio en el mismo servicio y reutilizará /data.

DESPUÉS DEL DESPLIEGUE
1. Abre el panel y verifica que aparezca V4.8.3 Profesional.
2. Revisa Clientes y cobros; tus registros deben continuar visibles.
3. Abre WhatsApp y pulsa "Cerrar sesión" si deseas descartar la sesión dañada.
4. Confirma el aviso. El botón mostrará "Cerrando sesión..." mientras trabaja.
5. Espera hasta 20 segundos. El diagnóstico debe mostrar una revisión WA
   2.3000.104... y aparecerá el QR nuevo.
6. Si un candidato es rechazado con 405, no pulses ningún botón: el bot
   cambiará automáticamente al siguiente.
7. Escanea el QR una sola vez y espera a que el panel indique "Conectado".
8. Prueba Modo noche, el menú y una búsqueda de cliente.
9. Conserva el respaldo descargado hasta terminar las comprobaciones.

IMPORTANTE
- La versión de la aplicación es 4.8.3.
- La versión interna de datos continúa siendo 4.7 de forma intencional.
- No cambies src/defaults.js a 4.8: no hace falta migrar la base para renovar
  únicamente la interfaz.
- No crees manualmente WHATSAPP_WEB_VERSION en Render. El bot consulta la
  revisión vigente en cada inicio y ya incluye alternativas de respaldo.
- Esta versión mantiene el modo de bienvenida única y no agrega IA, Qwen u
  Ollama.
