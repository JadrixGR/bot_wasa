ANTES DE ACTUALIZAR
1. En el panel actual entra a Clientes y cobros.
2. Pulsa Descargar respaldo JSON y guárdalo en tu computadora.
3. Confirma en Render que el Persistent Disk siga montado en /data.
4. Confirma que DATA_DIR=/data.
5. No elimines ni reemplaces el disco persistente.

SUBIR A GITHUB
1. Descomprime este ZIP.
2. Copia el contenido de jadrixservs-bot-v4 sobre tu repositorio actual.
3. No borres la carpeta .git.
4. Ejecuta:

   git add -A
   git commit -m "Actualizar JadrixServs a V4.7.2"
   git push

DESPUÉS DEL DESPLIEGUE
1. Abre el panel.
2. Pulsa Modo noche.
3. Recarga la página para confirmar que la preferencia permanece.
4. Revisa que tus clientes sigan visibles.

IMPORTANTE
Esta versión no incluye IA, Qwen ni Ollama.
