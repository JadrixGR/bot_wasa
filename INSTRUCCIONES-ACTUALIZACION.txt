1. Copia estos archivos dentro de tu carpeta local whatsapp-qr-render-bot.
2. Acepta reemplazar los archivos anteriores.
3. Abre PowerShell dentro de esa carpeta.
4. Ejecuta:

   git add .
   git commit -m "Cambiar conexion a Baileys"
   git push

5. Espera el nuevo despliegue de Render.
6. En WhatsApp del teléfono, elimina el dispositivo vinculado anterior.
7. En el panel del bot, pulsa "Cerrar sesión y nuevo QR".
8. Escanea el QR nuevo.
