JADRIXSERVS BOT V4.7.1 - ACTUALIZACIÓN SEGURA SIN PERDER CLIENTES

NOVEDADES
- Colores por días restantes en Clientes:
  * Verde: faltan entre 3 y 30 días.
  * Amarillo: faltan 2 días, 1 día o vence hoy.
  * Rojo: el servicio ya venció.
  * Neutral: faltan más de 30 días.
- El número de WhatsApp se copia al hacer clic.
- Cada número admite hasta 2 compras o servicios.
- Botón "Eliminar registro" para borrar una sola compra.
- Botón "Eliminar cliente" para borrar todas las compras del número.

PROTECCIÓN DE DATOS
Esta versión usa exactamente el mismo archivo persistente:
/data/jadrixservs-v4.json

No incluye una base vacía y no cambia el formato de los registros existentes. Al iniciar, lee la base actual y conserva clientes, fechas, servicios, mensajes, configuración y sesión de WhatsApp. Antes de cada escritura mantiene una copia automática en:
/data/jadrixservs-v4.backup.json

Al primer inicio de V4.7.1 también crea una copia fija previa a la actualización en:
/data/jadrixservs-v4.pre-v4.7.1.json

ANTES DE ACTUALIZAR
1. En el panel actual abre Clientes y cobros.
2. Pulsa "Descargar respaldo JSON" y guarda el archivo.
3. Confirma en Render que DATA_DIR=/data y que existe un Persistent Disk montado en /data.
4. No borres el disco ni la carpeta /data.

SUBIR A GITHUB
1. Descomprime este ZIP.
2. Copia el contenido de la carpeta jadrixservs-bot-v4 sobre tu repositorio actual.
3. No borres la carpeta .git.
4. Ejecuta:
   git add -A
   git commit -m "Actualizar JadrixServs a V4.7.1"
   git push
5. Espera a que Render termine el despliegue.

DESPUÉS DEL DESPLIEGUE
- Abre Clientes y cobros y comprueba que aparezcan tus registros anteriores.
- Prueba haciendo clic en un número para copiarlo.
- Crea una segunda compra para un mismo número.
- El intento de crear una tercera compra mostrará una advertencia y no modificará la base.

IMPORTANTE
"Eliminar registro" y "Eliminar cliente" sí eliminan información después de confirmar. La copia automática conserva el estado inmediatamente anterior, pero también es recomendable descargar respaldos JSON periódicamente.
