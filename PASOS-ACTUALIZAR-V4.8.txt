JADRIXSERVS BOT V4.8 PROFESIONAL - ACTUALIZACIÓN SEGURA
========================================================

QUÉ CAMBIA
- Nuevo diseño profesional, animado y adaptable a celular.
- Acceso, resumen, navegación, WhatsApp, clientes, mensajes, AFK y actividad
  tienen una presentación renovada.
- Se conservan todas las funciones de V4.7.2.
- No cambia el esquema de la base, los clientes ni la sesión vinculada.

ANTES DE ACTUALIZAR
1. En el panel actual abre Clientes y cobros.
2. Pulsa "Descargar respaldo JSON" y guarda el archivo en tu computadora.
3. En Render abre tu MISMO servicio y entra a Disks.
4. Confirma:
   - Disk: jadrixservs-data
   - Mount Path: /data
   - DATA_DIR=/data
   - MEDIA_DIR=/data/media
5. No elimines, reemplaces ni desconectes el disco.
6. No crees otro servicio de Render para esta actualización.

ARCHIVOS QUE SE CONSERVAN EN RENDER
- /data/jadrixservs-v4.json             Base principal
- /data/jadrixservs-v4.backup.json      Copia automática
- /data/jadrixservs-v4.pre-v4.7.2.json  Copia fija existente
- /data/whatsapp-session                Sesión de WhatsApp
- /data/media                           Archivos multimedia

SUBIR A GITHUB
1. Descomprime JadrixServs-Bot-V4.8-Profesional.zip.
2. Copia el contenido de jadrixservs-bot-v4 sobre tu repositorio actual.
3. Acepta reemplazar los archivos, pero NO borres la carpeta .git.
4. Desde PowerShell ejecuta:

   git add -A
   git commit -m "Actualizar JadrixServs a V4.8 Profesional"
   git push

5. Render desplegará el cambio en el mismo servicio y reutilizará /data.

DESPUÉS DEL DESPLIEGUE
1. Abre el panel y verifica que aparezca V4.8 Profesional.
2. Revisa Clientes y cobros; tus registros deben continuar visibles.
3. Abre WhatsApp y confirma que el estado pase a Conectado.
4. Prueba Modo noche, el menú y una búsqueda de cliente.
5. Conserva el respaldo descargado hasta terminar las comprobaciones.

IMPORTANTE
- La versión de la aplicación es 4.8.0.
- La versión interna de datos continúa siendo 4.7 de forma intencional.
- No cambies src/defaults.js a 4.8: no hace falta migrar la base para renovar
  únicamente la interfaz.
- Esta versión mantiene el modo de bienvenida única y no agrega IA, Qwen u
  Ollama.
